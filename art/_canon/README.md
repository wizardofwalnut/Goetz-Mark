# Canon set (Sep 4-5 Grok diorama pass)

Copied Oct 12 from the user's Downloads (random Grok file names renamed by
what they show). Reference for what each asset should look like; shown in
`art/ART_BOOK.pdf` wherever no new art exists yet. Not accepted game art.

- `castle-1..5-*` from `aldermarch_castle_tiers.zip` (5 tiers).
- `unit-*` troop icons: `unit-knight-plate` and `unit-pikeman` are full files;
  the rest are ~280 px cells cut from `_index-units.jpg`.
- `labor-*`, `industry-*`, `village-*`, `town-house`, `field-*`, `land-meadow`,
  `wagon-caravan`, `siege-ram`: single full-size files.
- `scene-*`: concept scenes, style reference only (never cut into tiles).
- `_index-*`: the labelled contact sheets.
- Not found on the computer: farmer and herder laborers, bow and other
  weapon icons, mercenary.
