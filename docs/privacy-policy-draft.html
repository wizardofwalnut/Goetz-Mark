Aldermarch — Privacy Policy

Last updated: [DATE]

Aldermarch is a single-player strategy game that runs entirely on your device. This page explains what that means for your information. In short: the game does not collect, send or share any personal data.

What the game stores

Your saved games and settings (for example, whether music or tips are on) are stored in your browser's local storage on your own device. They never leave it. Uninstalling the game or clearing the app's or browser's data deletes them.

What the game sends

Nothing. Aldermarch has no accounts, no analytics, no advertising and no online features. It makes no network requests other than downloading the game itself. Once installed, it can be played offline, and a copy is kept on your device so it can start without a connection.

The website that hosts the game

The game is downloaded from GitHub Pages. As with any website, GitHub may keep standard technical logs of requests (such as IP addresses) under GitHub's own privacy statement. Aldermarch itself does not receive or use that information.

Children

Because the game collects no personal information from anyone, it collects none from children.

Changes

If a future version adds anything that handles personal data, such as purchases or online saves, this page will be updated before that version is released, and the date at the top will change.
